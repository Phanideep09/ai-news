How this stays running

Checks run automatically on GitHub's servers every ~3 hours — not your computer. Notifications and new articles keep coming even if your laptop is off, asleep, or far away.

Test notifications

Go to your GitHub repository → Actions tab → select "Send test notification" → click Run workflow. You should get a push within a few seconds.

Reset & rescan everything

Go to Actions → "Check AI feeds" → Run workflow → type yes into the reset box → Run. This makes every current article look new again.
